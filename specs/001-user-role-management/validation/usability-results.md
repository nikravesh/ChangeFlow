# نتایج ارزیابی کاربردپذیری SC-001 و SC-005

**وضعیت**: اجرا نشده — نیازمند حداقل ۲۰ شرکت‌کننده واقعی نماینده کاربران هدف  
**Feature**: `001-user-role-management`

این فایل پروتکل و فرم ثبت شواهد است. هیچ داده مصنوعی یا نتیجه فرضی نباید در آن ثبت شود.

## پروتکل ثابت

1. شرکت‌کننده بدون راهنمایی، نام نمایشی، شناسه ورود، password معتبر و Role را برای ایجاد User وارد می‌کند.
2. زمان از نمایش سناریو تا دریافت پاسخ موفق ثبت می‌شود.
3. برای SC-005 یک درخواست با خطای validation ازپیش‌تعریف‌شده نمایش داده می‌شود.
4. تشخیص مستقل علت و موفقیت تلاش اصلاحی بدون کمک ثبت می‌شود.
5. Setup Code و password واقعی در این سند نوشته نمی‌شوند.
